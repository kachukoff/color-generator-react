# 🎨 Генератор и Менеджер Цветов (Vite + React)

Современное, модульное веб-приложение на React для генерации, валидации и удобного хранения цветовых кодов в различных форматах. Проект разработан в рамках выполнения практического домашнего задания.

---

## 🚀 Ключевой функционал

* **Мгновенная валидация «на лету»** — Проверка корректности имени цвета (строго буквы) и кодов формата (`HEX`, `RGB`, `RGBA`) прямо в процессе ввода с выводом понятных ошибок на русском языке.
* **Умная группировка карточек** — При добавлении нового формата для уже существующего цвета данные не дублируются, а аккуратно записываются в существующую карточку.
* **Интерактивное превью без лишних кнопок** — Фоновый цвет карточки динамически переключается при обычном клике на плашку с нужным форматом кода.
* **Точечное удаление** — Возможность удалить конкретный формат кода из карточки (при удалении последнего формата карточка полностью стирается).
* **Синхронизация с Cookie** — Коллекция цветов автоматически кэшируется в браузере пользователя со сроком жизни ровно 3 часа.

---

## 🛠️ Технологический стек

* **Библиотека**: React (Hooks: `useState`, `useEffect`)
* **Сборщик**: Vite
* **Стилизация**: Sass (SCSS) / Bootstrap 5
* **Архитектура**: Разделение бизнес-логики (папка `src/helpers/`) и интерфейса (React-компоненты)

---

## 📂 Архитектура проекта

Код отрефакторен по принципам чистой архитектуры (Clean Code):
* `src/helpers/colorValidators.js` — изолированная логика регулярных выражений (Regex) для валидации ввода.
* `src/helpers/cookieStorage.js` — безопасное кодирование данных (`encodeURIComponent`) и работа со встроенными хранилищами.
* `src/components/` — компактные, изолированные компоненты формы и полей ввода.

## 💻 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone git@github.com:kachukoff/color-generator-react.git
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd color-generator-react
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
